# FaceBook-Clone
Welcome to the Facebook Clone project, a social media application that replicates key features of Facebook. This project demonstrates my front-end and back-end development skills, showcasing my ability to create interactive and user-friendly web applications.

# Features
User Authentication: Users can sign up, log in, and manage their profiles securely.
Post Creation: Users can create, edit, and delete posts, sharing thoughts and updates with their friends.
Comment and Like Functionality: Engage with posts through comments and likes, fostering interaction.
Friend System: Users can send and accept friend requests to connect with others.
Responsive Design: Fully responsive layout optimized for various devices, ensuring a great user experience.

# Tech Stack
Front-End: HTML, CSS, JavaScript
